# Création du dépôt GitHub — procédure minimale

## À faire une seule fois

1. Ouvrir GitHub dans le navigateur.
2. Cliquer sur **New repository**.
3. Propriétaire : `Philipppri`.
4. Nom recommandé : `pechescore-tide-data`.
5. Visibilité : **Public**.
6. Cocher **Add a README file**.
7. Ne pas choisir de licence générique pour les données à ce stade.
8. Créer le dépôt.
9. Dans GitHub Desktop : **File > Clone repository**, puis cloner ce nouveau dépôt.
10. Copier dans le dépôt les fichiers de ce kit, sans le dossier parent.
11. Commit : `Initialize PêcheScore tide data repository`.
12. Push.

## Ne pas faire maintenant

- ne pas créer de release de données ;
- ne pas téléverser les NetCDF/XZ ;
- ne pas ajouter de token GitHub dans l’application ;
- ne pas rendre public le dépôt privé du code PêcheScore.

La première release sera créée seulement quand les assets finaux et le manifest auront été générés et validés.
