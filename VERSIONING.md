# Versionnement

## Releases

Format recommandé :

`fes2022b-pechescore-vMAJEUR.MINEUR.CORRECTIF`

Exemple :

`fes2022b-pechescore-v1.0.0`

## Règles

- **MAJEUR** : format binaire incompatible ;
- **MINEUR** : nouvelles zones, nouvelles métadonnées ou amélioration compatible ;
- **CORRECTIF** : correction d’asset sans modification de format.

Une release publiée est immuable. Toute correction utilise un nouveau tag.
